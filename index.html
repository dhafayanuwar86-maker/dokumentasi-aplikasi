SEOPulse

Aplikasi PHP + MySQL. Proses instalasi membuat database, tabel, dan file config.php berisi kredensial database.

Kebutuhan

  • PHP 8 dengan ekstensi PDO MySQL.
  • MySQL/MariaDB dan satu database beserta user database.
  • HTTPS dan direktori web yang tidak bisa di-list.

Instalasi di cPanel

  1. Upload arsip aplikasi ke folder tujuan, lalu extract.
  2. Buat database + user database di cPanel; berikan hak akses penuh.
  3. Buka /install.php, isi kredensial database dan akun administrator.
  4. Setelah sukses, hapus install.php dari web root.

Keamanan: config.php menyimpan kredensial database dalam bentuk teks di server. Jangan pernah meng-commit atau mempublikasikan file ini.

WP Central

Dashboard terpusat untuk merawat banyak situs WordPress. Dibangun dengan PHP 8 + SQLite: tanpa MySQL, tanpa Composer, tanpa build asset.

Kebutuhan server

  • PHP 8.0+ dengan ekstensi pdo_sqlite, sqlite3, curl, mbstring, openssl, zip.
  • Apache/LiteSpeed dengan .htaccess standar cPanel.
  • Folder aplikasi writable untuk config.php, data/, dan reports/.

Instalasi di cPanel

  1. Upload wp-central.zip ke folder tujuan, lalu extract supaya index.php, install.php, core/ berada langsung di folder tersebut.
  2. Set permission folder ke 755.
  3. Buka /install.php; isi nama workspace, akun admin, zona waktu, dan URL aplikasi. Salin Cron URL yang muncul.
  4. Tambah cron cPanel tiap 5 menit: 
    curl -s "https://panel.domainanda.com/cron.php?key=CRON_KEY_ANDA" > /dev/null
  5. Aktifkan HTTPS dan backup berkala file data/wpcentral.sqlite.

Menghubungkan situs WordPress

  1. Di panel: Situs → Tambah situs, lalu simpan token konektor dari tab Pengaturan.
  2. Di WordPress target: upload dan aktifkan wp-central-connector.zip.
  3. Buka Settings → WP Central, isi URL dashboard (tanpa /api.php) dan token, lalu Simpan.
  4. Klik Sinkronisasi Sekarang. Job update/backup/scan dijalankan WP-Cron tiap 5 menit.

Keamanan: token konektor bersifat rahasia; rotasi bila bocor. Folder core/, modules/, data/, reports/, dan uploads/ harus mengembalikan 403 untuk publik. File data/wpcentral.sqlite adalah seluruh database panel.

Catatan

Halaman ini sengaja tidak memuat kata sandi, token produksi, atau kredensial database. Untuk akses aplikasi, gunakan kredensial yang tersimpan di OpenBot Vault. Informasi instalasi di atas ringkasan dari README aplikasi; rincian lengkap ada di repository kode masing-masing.
